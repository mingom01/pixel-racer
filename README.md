# 픽셀 레이서 (PIXEL RACER)

친구들과 같이 하는 3D 픽셀 레이싱 게임. 설치할 패키지 없이 Node.js만 있으면 돌아갑니다.

## 실행

```
node server.js
```
또는 `run.bat` 더블클릭 → http://localhost:8160

서버 창에 `같은 와이파이의 친구는: http://192.168.x.x:8160` 주소가 나오는데, 같은 와이파이에 있는 친구는 그 주소로 들어오면 됩니다.

## 게임 내용

- **로그인**: 구글 로그인 또는 게스트(닉네임). 게스트로 모은 코인·차는 나중에 같은 브라우저에서 구글 로그인하면 옮겨집니다.
- **방**: 공개 방(로비 목록에 표시) / 비공개 방(5자리 코드를 아는 사람만). 빠른 참가 버튼은 사람이 많은 공개 방으로 들어갑니다.
- **자유 주행**: 도시, 그랑프리 서킷, 점프대가 있는 스턴트 파크, 들판을 마음대로 돌아다닐 수 있습니다.
- **레이스**: 방장이 Esc 메뉴에서 코스(그랑프리 서킷 / 다운타운 런)와 바퀴 수를 고르고 시작합니다. 방에 있는 사람 모두 출발선으로 이동합니다.
- **코인**: 길 위의 금화는 5코인, 초록 보석(점프대 위 공중 등)은 25코인. 레이스 순위에 따라 보너스 코인. 먹은 코인은 조금 뒤에 다시 생깁니다.
- **차고**: 코인으로 실제 차 19종을 사고 색을 바꿀 수 있습니다.
- **드리프트**: Space 를 누른 채 코너를 돌면 속도를 거의 유지하며 미끄러지고, 1초 이상 드리프트 후 떼면 미니 부스트.
- **범퍼카 충돌**: 다른 차를 들이받으면 상대가 밀려나고, 앞뒤 끝을 박으면 빙글 돕니다. 무거운 차(버스, G클래스, F-150)일수록 세게 밀어냅니다.

## 레이싱 방 (그랑프리)

방 만들기에서 **레이싱 방**을 고르면 자유 주행과 다른 전용 경쟁 모드가 열립니다.

- **대기실**: 모두 **준비**를 누르면 방장이 **게임 시작**. 기다리는 동안 **연습 주행** 가능.
- **전용 트랙 4개** (벽으로 막힌 코스): 코리아 그랑프리(F1 서킷) · 사막 점프 랠리 · 아이스 드리프트(빙판) · 네온 시티 나이트(야간)
- **스피드전**: 드리프트로 게이지를 채우면 니트로(최대 2개). `E`/`Shift`/휴대폰 니트로 버튼.
- **아이템전**: 물음표 박스에서 아이템(최대 2개) — 부스터, 바나나, 물폭탄, 미사일(앞사람 추적), 실드, 자석. 뒤처질수록 공격/부스터 아이템이 잘 나와요. `E`/`Shift` 사용, `Q` 순서 바꾸기.
- **F1 방식**: 예선(75초 타임어택, 충돌 없음)으로 출발 순서 결정 · 1위가 들어오면 12초 뒤 종료(나머지 DNF) · 포인트 25/18/15/12/10/8/6/4/2/1 + 최고 랩 1점 · 방 안에서 시즌 순위 누적
- **팀전**: 레드/블루 팀 포인트 합산으로 승부.
- 레이스 중에 들어온 사람은 관전(클릭/Space 로 다른 사람 보기)하다가 다음 레이스부터 참가.

### 조작
`WASD`/방향키 운전 · `Space` 드리프트 · `R` 도로로 복귀 · `C` 카메라 · `H` 경적 · `M` 전체 지도 · `Enter` 채팅 · `Esc` 메뉴.
**휴대폰**: 왼쪽 아래 패드를 좌우로 드래그해서 핸들(누른 곳 기준 아날로그) · 오른쪽 GO(가속) / 브레이크(후진) / 드리프트 · 오른쪽 위 버튼으로 복귀·카메라·경적·지도·채팅·전체화면 · 메뉴 → 설정에서 `자동 가속`, `버튼 핸들` 선택. 세로/가로 모두 지원하고 게임 중엔 화면이 꺼지지 않아요.

## 구글 로그인 켜기

1. https://console.cloud.google.com 에서 프로젝트를 만듭니다.
2. **API 및 서비스 → OAuth 동의 화면**: 사용자 유형 "외부", 앱 이름/이메일 입력 후 저장.
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 JavaScript 원본: `http://localhost:8160`, `http://localhost` (배포했다면 그 https 주소도 추가)
4. 만들어진 **클라이언트 ID**(`xxxx.apps.googleusercontent.com`)를 `config.json` 에 넣습니다.
   ```json
   { "port": 8160, "googleClientId": "xxxx.apps.googleusercontent.com" }
   ```
5. 서버를 다시 켭니다.

> 구글 로그인은 `localhost` 또는 `https://` 주소에서만 됩니다. 와이파이 IP(`http://192.168.x.x`)로 들어온 친구는 게스트로 하거나, 아래처럼 https 주소를 만들어 주세요.

## 인터넷에 올리기 (Render + Supabase, 무료)

친구들이 어디서든 접속하고, 구글 계정에 코인·차가 저장되게 하는 방법입니다.

### 1. Supabase (계정 저장용 DB)
1. https://supabase.com 가입 → **New project** (지역: Northeast Asia (Seoul))
2. 왼쪽 **SQL Editor** → 이 저장소의 `supabase.sql` 내용을 붙여넣고 **Run**
3. **Project Settings → API Keys** 에서 두 값을 복사
   - **Project URL** (`https://xxxx.supabase.co`)
   - **secret 키** (`sb_secret_...`, 예전 화면이면 `service_role` 키) — 절대 공개하지 마세요

### 2. Render (게임 서버)
1. https://render.com 에 GitHub 로 가입 → **New → Blueprint** → 이 저장소 선택 (`render.yaml` 대로 만들어짐)
2. 환경변수 입력: `SUPABASE_URL`, `SUPABASE_SECRET_KEY`, `GOOGLE_CLIENT_ID`(3번에서)
3. 배포가 끝나면 `https://pixel-racer-xxxx.onrender.com` 같은 주소가 생깁니다. 이 주소를 친구에게 공유!
   - 무료 서버는 15분 동안 아무도 없으면 잠들어서, 처음 접속할 때 1분쯤 걸려요.

### 3. 구글 로그인
아래 "구글 로그인 켜기"대로 클라이언트 ID를 만들고, **승인된 JavaScript 원본**에 Render 주소(`https://….onrender.com`)를 추가 → 그 ID를 Render 환경변수 `GOOGLE_CLIENT_ID` 에 넣으면 끝.

> GitHub 에 push 하면 Render 가 자동으로 다시 배포합니다. 계정은 Supabase 에 있으니 재배포해도 코인·차가 그대로예요.
> 게스트로 하던 사람은 로비의 **구글로 저장하기** 버튼으로 지금까지 모은 걸 구글 계정으로 옮길 수 있어요.

## 같은 와이파이 / 터널

- 같은 와이파이: 서버 창에 나오는 `http://192.168.x.x:8160` 주소 (구글 로그인은 안 되고 게스트만)
- Cloudflare 터널: `cloudflared tunnel --url http://localhost:8160` → `https://….trycloudflare.com` (주소가 매번 바뀜)
